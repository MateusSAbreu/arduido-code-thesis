Este repositório contém os códigos Arduino desenvolvidos e utilizados no âmbito da tese.

- "codigo_principal_arduino/"
  Código principal utilizado para controlar o sistema desenvolvido na tese.

- "calibracao_lcd_touch/"
  Código utilizado para a calibração do ecrã LCD touch.

-> Código principal Arduino

O código principal foi utilizado para controlar o funcionamento do protótipo desenvolvido, permitindo a execução dos movimentos/ações necessárias durante os ensaios experimentais.
Este código inclui a lógica de controlo do sistema, a comunicação com os componentes eletrónicos utilizados e a execução dos parâmetros definidos para o procedimento experimental.

-> Código de calibração do LCD touch

O código de calibração do LCD touch foi utilizado para ajustar corretamente a leitura das coordenadas do ecrã tátil.
A calibração permite garantir que os pontos tocados no ecrã correspondem corretamente às posições reconhecidas pelo sistema, melhorando a precisão da interface gráfica.

-> Requisitos:

- Arduino IDE
- Placa Arduino compatível
- Ecrã LCD touch compatível
- Bibliotecas necessárias para o LCD touch e restantes componentes utilizados

-> Utilização

1. Abrir o ficheiro ".ino" pretendido na Arduino IDE.
2. Selecionar a placa Arduino correta.
3. Selecionar a porta correspondente.
4. Compilar o código.
5. Fazer upload para a placa.

-> Nota: Os códigos foram desenvolvidos especificamente para o protótipo utilizado nesta tese. Poderão ser necessárias alterações caso sejam utilizados componentes diferentes.
